매장 / 좌석

PC방 매장과 공인 IP, 등록 좌석의 온라인 상태를 관리합니다.

최고 관리자는 매장을 등록하고 전체 좌석을 관리합니다. PC방 관리자는 지정된 자기 매장의 좌석 PC만 등록·관리합니다.

PC방 좌석용 Host 설치

실제 원격 접속 대상 PC에 설치합니다. Sunshine + PCROOM HOME Host Agent를 설치하고, 온라인 상태·GPU 스트리밍·WOL 상태를 서버에 자동 보고합니다.

좌석 PC: 1. PC 등록 → 2. 등록코드 발급 → 3. Host 설치 → 4. 코드 입력
전 좌석 OFF 대비: 매장 카드의 WOL 중계기 코드 발급 → 항상 켜진 카운터 PC에서 같은 Host 설치파일 실행
PC방 Host 설치파일 다운로드PCROOM-HOME-Host-Setup.exe · Windows 10/11 x64

호스트 등록코드

15분 동안 유효합니다. 좌석 PC 또는 항상 켜진 카운터 PC에서 Host Setup을 실행한 뒤 이 코드를 입력하세요. 중계기 코드는 Sunshine 없이 WOL relay만 설치합니다.
